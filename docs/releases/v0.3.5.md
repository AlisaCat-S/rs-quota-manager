# 周限与重置卡 v0.3.5 — RS v3.43.0 SDK

源码基线：v0.3.5；对应宿主：RS v3.43.0。

宿主兼容范围：`>=3.33.0, <3.44.0`。仍为 RPC v7，保留 RS v3.33–v3.42 兼容；公开安装包使用 UTC 时间版本号，以 Releases 的实际附件为准。

## 更新内容

- SDK、Cargo 锁文件与官方打包工具固定到 [RS v3.43.0](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.43.0) 提交 `402bc37fbb5c83378cc83cec89e9fa251e4a99c1`，新增 v3.40.0 至 v3.43.0 七份宿主合同快照。
- 已分析排队超时拆分、用量快照批量读取、账号额度点数和外链确认桥。插件不调用新增接口或修改宿主设置，现有账号、额度、状态和重置卡合同保持不变。
- UI 升至官方 v0.9.0，接受新版宿主的柔光材质；为缺少新阴影 token 的旧宿主保留原浮层阴影。保留中文控件、新旧主题桥和宿主主题注入。
- 无状态迁移，保留身份、设置、历史和未决操作；409 / 429、未知结果或会话中断仍保留原卡与原 UUID，不自动重放。

## 升级安装

1. 安装本次 SDK 重新构建、打包的新制品，不仅修改旧包清单或依赖一次性风险确认。
2. 按宿主架构选择 Linux x86_64 / ARM64 `.tar.gz`，要求 glibc >= 2.28；核对 `.sha256` 或 `checksums.txt` 后，通过插件管理安装和切换。本插件未提供 Windows / macOS 安装包。
3. 保留原实例、私有状态和回退包，核对页面、设置与运行状态。未决操作只通过“确认原操作”继续。

RPC v5/v6 宿主继续使用匹配的旧版插件。宿主的额度点数自动使用与本插件重置卡策略独立，本次不会开启或修改该设置。
