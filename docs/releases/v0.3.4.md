# 周限与重置卡 v0.3.4 — RS v3.39.1 SDK

源码基线：v0.3.4；对应宿主：RS v3.39.1。

宿主兼容范围：`>=3.33.0, <3.40.0`。仍为 RPC v7，保留 RS v3.33–v3.38 兼容；公开安装包使用 UTC 时间版本号，以 Releases 的实际附件为准。

## 更新内容

- SDK、Cargo 锁文件与官方打包工具固定到 [RS v3.39.1](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.39.1) 提交 `12c32fcdecb29da4e44a21bb33fbbf2aaf6a166d`，新增 v3.38.2 / v3.39.0 / v3.39.1 宿主合同快照。
- 已分析新增运行设置 `max_retry_after_seconds`、推理等待上限和实例 `secrets` 逐字段更新。本插件不调用运行设置或实例配置接口，所用 RPC 与账号、额度、状态、重置卡合同未变。
- 管理消费请求仍不自动重放；409 / 429、未知结果或会话中断继续保留原卡与原 UUID。
- UI 保持最新稳定版 v0.8.0，清单 v2、management v2、maintenance v1、页面桥 v2 和新旧主题兼容不变。
- 无状态迁移，保留身份、设置、历史和未决操作；不新增权限，不改变自动开关。

## 升级安装

1. 安装本次 SDK 重新构建、打包的新制品，不仅修改旧包清单或依赖一次性风险确认。
2. 按宿主架构选择 Linux x86_64 / ARM64 `.tar.gz`，要求 glibc >= 2.28；核对 `.sha256` 或 `checksums.txt` 后，通过插件管理安装和切换。宿主新增 Windows 版本不代表本插件提供 Windows 安装包。
3. 保留原实例、私有状态和回退包，核对页面、设置与运行状态。未决操作只通过“确认原操作”继续。

RPC v5/v6 宿主继续使用匹配的旧版插件。
