# 周限与重置卡 v0.3.0 — RS v3.33.0 / RPC v7

源码基线：v0.3.0；对应宿主：RS v3.33.0。

宿主兼容范围：`>=3.33.0, <3.34.0`。本版使用 RPC v7，不兼容 RPC v5/v6 宿主。公开安装包继续使用 `YYYYMMDD.HHMMSS.运行序号` UTC 版本，Release 同时标识本源码基线和对应宿主版本。

## 更新内容

- SDK 与官方打包工具同步至 [RS v3.33.0](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.33.0)，固定提交 `8c8618aa0f841638262262e3338c115bc075f125`，重新构建并生成 RPC v7 安装包。
- 使用新版 SDK 处理协作式挂起、宿主恢复授权和回调结果回收；维护巡检改用 SDK 剩余预算，计入前置查询、普通回调和恢复等待，保留保存巡检游标的时间。
- UI 更新至官方 v0.7.0，保留中文控件、分页、筛选、选卡确认、周预估金额和 CSV。
- 插件 ID `personal.quota-manager`、私有状态 schemaVersion 1、设置和历史记录不变，无状态迁移。已有未决消费继续确认原卡、复用原 UUID。

## 升级安装

升级 RS v3.33.0 时，请同时更新已安装插件。仅修改旧包的清单版本号或宿主兼容范围不能升级 RPC。

1. 选择本次 Release 中匹配宿主架构的 Linux x86_64 或 ARM64 `.tar.gz`，要求 glibc >= 2.28。
2. 按同名 `.sha256` 或 `checksums.txt` 校验文件，通过宿主插件管理安装并切换版本；不要上传 Source code 归档。
3. 保留原实例与私有状态，核对管理页、设置和运行状态。已有自动使用设置会保留；全新实例仍默认关闭。真实卡片消费不可撤回，不以真实消费验收升级。

旧宿主请继续使用与其协议匹配的插件；本仓库此前的 0.2.x 源码使用 RPC v5，不能在 RS v3.32.x 的 RPC v6 宿主上运行。
