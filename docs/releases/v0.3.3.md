# 周限与重置卡 v0.3.3 — RS v3.38.1 SDK

源码基线：v0.3.3；对应宿主：RS v3.38.1。

宿主兼容范围：`>=3.33.0, <3.39.0`。仍为 RPC v7，保留 RS v3.33–v3.37 兼容；公开安装包继续使用 UTC 时间版本号，以 Releases 的实际附件为准。

## 更新内容

- SDK、锁文件与官方打包工具固定到 [RS v3.38.1](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.38.1) 提交 `e0b7a841ca074f17e11dad73f39a159c75cb2fb1`，新增 v3.38.0 / v3.38.1 宿主合同快照检查。
- 已分析 SDK 内部模块重命名、CPR Link v2 命名窗口、模型调度及原生重置卡任务调整。插件所用公开接口未变；互联预算及池内额度不触发 OAuth 重置卡消费，缺失观测保持未知。
- UI 保持最新稳定版 v0.8.0，保留新旧主题桥兼容；清单 v2、management v2、maintenance v1 和页面桥 v2 不变。
- 无状态迁移，保留身份、设置、历史和未决操作；新实例自动使用默认关闭，不新增权限要求。

## 升级安装

1. 安装本次 SDK 重新构建、打包的新制品，不仅修改旧包清单或依赖一次性风险确认。
2. 按宿主架构选择 Linux x86_64 / ARM64 `.tar.gz`，要求 glibc >= 2.28；核对 `.sha256` 或 `checksums.txt` 后，通过插件管理安装和切换。
3. 保留原实例、私有状态和回退制品，核对页面、设置与运行状态。409 / 429 或未知结果仍保留原卡与原 UUID，只通过“确认原操作”继续。

RPC v5/v6 宿主继续使用匹配的旧版插件。CPR Link v2 的两端协调升级由宿主维护，不需要为本插件添加推理 Key 或启用互联分享。
