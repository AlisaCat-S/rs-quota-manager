# 周限与重置卡 v0.3.2 — RS v3.37.2 SDK

源码基线：v0.3.2；对应宿主：RS v3.37.2。

宿主兼容范围：`>=3.33.0, <3.38.0`。仍为 RPC v7，保留 RS v3.33–v3.36 兼容；公开安装包继续使用 UTC 时间版本号，以 Releases 的实际附件为准。

## 更新内容

- SDK 与官方打包工具固定到 [RS v3.37.2](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.37.2) 提交 `641f43b3030b1c68961e05d525e58ec6f4264a15`，锁文件同步更新。
- UI 升至官方 v0.8.0，迁移本地预览主题 API，并通过公开 `themePrefix` 配置同时兼容旧宿主的 `--cp-*` 和新宿主的语义 Token 主题桥。保留中文控件与宿主明暗切换。
- 清单 v2、management v2、maintenance v1 和页面桥 v2 不变；不引入模型目录、推理中间件、互联分享或 Key 权限要求。
- 无插件状态迁移，保留身份、设置、历史和未决操作；新实例自动使用仍默认关闭。API Key 账号即使有互联套餐或周额度，也不能执行卡片操作。

## 升级安装

1. 安装本次 SDK 重新构建、打包的新制品，不仅修改旧包清单或依赖一次性风险确认。
2. 按宿主架构选择 Linux x86_64 / ARM64 `.tar.gz`，要求 glibc >= 2.28；使用 `.sha256` 或 `checksums.txt` 校验，通过插件管理安装并切换，不上传 Source code 归档。
3. 保留原实例、私有状态和回退制品，核对页面主题、设置及运行状态。原自动开关和未决操作会保留，不用真实消费测试升级。

RPC v5/v6 宿主继续使用匹配的旧版插件。消费结果不确定或遇到 409 / 429 时仍暂停并保留原卡与原 UUID，只通过“确认原操作”继续。
