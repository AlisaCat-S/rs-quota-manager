# 周限与重置卡 v0.1.5

更新宿主兼容声明，支持 RS 3.27 系列，避免在 RS v3.27.1 上继续显示旧的 `<3.27.0` 兼容性提醒。

## 变更

- 宿主范围从 `>=3.26.2, <3.27.0` 更新为 `>=3.26.2, <3.28.0`。
- 保留当前界面中的检测数值居中、单位外置等已交付调整。
- 不改动业务实现、私有状态结构、自动开关、卡片选择、消费幂等或历史记录规则。
- 本插件仍排除 Free 账号；Free 支持仅属于独立的账号重新授权插件，不将该规则混用。
- 原始套餐、账号启用状态、分组和代理保持不变。

## 验证

- 核对 RS v3.26.2 至 v3.27.1 的相关账号、额度和卡片接口契约，无需修改当前业务调用。
- 本机构建通过，包括 3 项 Rust 规则测试、27 项真实 SDK 进程协议场景及 11 项前端契约测试。
- 与账号重新授权插件共同通过 514 项静态接入检查。
- Linux x86_64 安装包在本机交叉编译，使用官方 CLI 打包，6 个内部文件摘要核对通过。
- 无网络、非 root、只读根目录的独立容器验收通过，限制 64 MiB 内存和 0.25 CPU，验证握手、管理页注册和默认关闭自动消费。
- 不通过验收执行真实卡片查询、消费、开启自动使用或账号重新授权。

## 安装

- 插件 ID：`personal.quota-manager`
- 宿主兼容：RS `>=3.26.2, <3.28.0`
- 平台：Linux x86_64，glibc 2.28 及以上
- GitHub 仓库：`Lemon-57/rs-quota-manager`
- 标签：`v0.1.5`
- 下载 `.tar.gz` 安装包并核对 `.sha256` 或 `checksums.txt`，Source code 不是插件安装包。
- 已有安装使用宿主版本切换，保留原实例、设置和历史。

自动消费仍默认关闭。真实卡片消费不可撤回，正式启用前请核对账号、卡片和使用范围。
