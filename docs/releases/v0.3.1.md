源码基线：v0.3.1；对应宿主：RS v3.34.0。

宿主兼容范围：`>=3.33.0, <3.35.0`。仍为 RPC v7，保留 RS v3.33.x 兼容；公开安装包继续使用 `YYYYMMDD.HHMMSS.运行序号` UTC 版本，以 Releases 的实际附件为准。

## 更新内容

- SDK 与官方打包工具固定到 [RS v3.34.0](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.34.0) 提交 `47d30474af7c3e1fab433f2d4a70430fae548ff2`，锁文件同步更新。
- 扩大宿主范围，适配 v3.34.0 不兼容插件不自动启动的规则；management v2、maintenance v1、manifest v2 和页面桥 v2 不变，不添加模型目录或 Key 权限要求。
- 受管推理的 429 有限重放不适用于重置卡 POST；新增回归验证 429 不自动重发，以及消费后会话中断、重启确认仍复用原卡和原 UUID。
- 无状态迁移，保留插件身份、设置、历史和未决操作；全新实例自动使用仍默认关闭。UI 仍为官方 v0.7.0。

## 升级安装

RS v3.34.0 会阻止宿主范围不匹配的旧包自动启动。请安装本次构建的新包，不依赖每次宿主重启后重新确认风险。

1. 选择匹配宿主架构的 Linux x86_64 或 ARM64 `.tar.gz`，要求 glibc >= 2.28。
2. 使用同名 `.sha256` 或 `checksums.txt` 校验，通过宿主插件管理安装并切换版本；不要上传 Source code 归档。
3. 保留原实例与私有状态，核对页面、设置和运行状态。原自动使用设置会保留，不以真实卡片消费测试升级。

RPC v5/v6 宿主继续使用对应旧版插件。RS v3.33.x 用户可以安装本版，也可继续使用原 0.3.0 源码对应的发行包。
