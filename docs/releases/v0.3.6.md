# 周限与重置卡 v0.3.6 — RS v3.44.0 SDK

源码基线：v0.3.6；对应宿主：RS v3.44.0。

宿主兼容范围：`>=3.33.0, <3.45.0`。仍为 RPC v7，保留 RS v3.33–v3.43 兼容；公开安装包使用 UTC 时间版本号，以 Releases 的实际附件为准。

## 更新内容

- SDK、Cargo 锁文件与官方打包工具固定到 [RS v3.44.0](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.44.0) 提交 `c622f085748f812936a7371fcc85d1621fa72ca8`，新增 v3.43.1 / v3.44.0 两份宿主合同快照。
- 已分析新增代理目录 / 指定代理 HTTP、重新授权身份更新、额度归属和连接测试诊断。重置卡继续使用宿主管理分发，不调用新代理接口，不新增配置、凭据或权限要求。
- 补充生图 / Codex 周限隔离回归：图片额度不触发重置或确认恢复，也不掩盖 Codex 周限耗尽。额度头归属修复来自宿主，旧宿主需自身升级。
- UI 升至官方 v0.9.1，材质与圆角尺寸解耦；保留中文控件、新旧主题桥和旧宿主浮层阴影，生产页继续使用宿主注入主题。
- 无状态迁移，保留身份、设置、历史和未决操作；409 / 429、未知结果或会话中断仍保留原卡与原 UUID，不自动重放。

## 升级安装

1. 安装本次 SDK 重新构建、打包的新制品，不仅修改旧包清单或依赖一次性风险确认。
2. 按宿主架构选择 Linux x86_64 / ARM64 `.tar.gz`，要求 glibc >= 2.28；核对 `.sha256` 或 `checksums.txt` 后，通过插件管理安装和切换。本插件未提供 Windows / macOS 安装包。
3. 保留原实例、私有状态和回退包，核对页面、设置与运行状态。未决操作只通过“确认原操作”继续。

RPC v5/v6 宿主继续使用匹配的旧版插件。宿主额度点数和临期重置卡自动化仍与本插件策略独立，本次不修改这些设置。
