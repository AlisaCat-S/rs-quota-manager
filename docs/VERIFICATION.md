# v0.1.3 验证说明

## 自动化验证

- 3 项 Rust 规则测试：通用周限判断、最早到期有效卡选择、恢复观测时间。
- 27 项协议测试：SDK v2 握手、分页、Free 排除、设置版本冲突、自动开关同步、账号停用状态保留、周限复核、幂等与重启恢复。
- 11 项前端用例：宿主桥、GET/POST 约束、相对路径、JSON 和错误处理、响应解码、游标编码、原请求标识、CSV 公式转义。
- Rustfmt、严格 Clippy、前端类型检查与生产构建通过。

执行方式见根目录 README。协议测试使用本机真实插件进程和模拟宿主，不调用真实上游。
Linux 下可在构建后指定二进制：`node verification/protocol-test.mjs backend/target/debug/quota-manager`。

## 页面与安装验证

- 在 RS v3.26.2 安装并验证管理页面、真实宿主桥、账号套餐同步、Free 排除、会员筛选、分页及页容量选择。
- 已核对设置、账号启用/分组及历史记录保留，自动消费保持关闭。
- 验证 1440px 桌面和 390px 窄屏、浅色与深色主题、邮箱显示、卡片单选及手动确认。
- CSV 复制用模拟数据验证；安装后的隔离页面验证只读内容与全选，未将真实账号内容复制或公开。
- 安装包内所有文件摘要与清单一致，所有编译和构建均在本机执行。

## 限制

实际验证的宿主版本只有 v3.26.2；清单允许 `>=3.26.2, <3.27.0`，不代表范围内每一版本都单独实测。
当前只提供 Linux x86_64 / glibc 2.28+ 制品。
自动消费与手动消费通过模拟上游测试，未执行真实卡片消费，不能据此保证所有上游套餐和卡片格式均已验证。
README 截图均来自本地预览；生产地址、账号数据、运维脚本和运行快照不进入公开仓库。
