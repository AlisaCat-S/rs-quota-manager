# 周限与重置卡 v0.1.3

RS 网关独立管理页插件，用于查看非 Free 账号的周额度、周额度刷新时间、有效重置卡数量和到期时间，并提供手动或可选自动使用重置卡。

## 安装

在“插件管理 → 安装插件 → GitHub”填写 `Lemon-57/rs-quota-manager`，标签 `v0.1.3`，选择 `.tar.gz` 资产；也可下载资产及 `checksums.txt`，核对 SHA-256 后上传安装。
插件 ID 为 `personal.quota-manager`，自动使用默认关闭。

## 兼容

- 宿主：`>=3.26.2, <3.27.0`；实际安装验证 v3.26.2。
- 平台：Linux x86_64，glibc 2.28+；本次未提供 ARM64 或 Windows 安装包。
- 基于宿主公开 SDK 和 `@codex-proxy/ui` v0.4.1，沿用官方示例的宿主桥与响应校验组织方式。

## 功能

- 显示完整邮箱，按会员标识、状态搜索筛选，支持分页及每页 10/20/50/100 条。
- 检测设置内联展示，自动总开关同步逐号状态，支持逐号排除。
- 手动选卡确认，自动使用前复核通用周限，优先最早到期有效卡。
- 持久化原请求标识，结果不确定时暂停该号消费，保留原请求确认入口。
- 随宿主主题切换，CSV 通过只读弹窗、复制和全选导出，不放宽隔离权限。

## 验证与风险

3 项规则测试、27 项协议测试和 11 项前端测试通过；已验证真实宿主安装和管理页面。
未进行真实卡片消费，自动/手动消费路径使用模拟上游验证。启用自动使用或确认手动消费可能真实消耗重置卡，操作不可撤回。
请先核对账号、周限和库存，按需开启自动使用。关闭开关不能撤回已经发出的消费请求。
