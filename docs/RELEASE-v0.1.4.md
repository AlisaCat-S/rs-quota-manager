# 周限与重置卡 v0.1.4

RS 网关独立管理页插件，用于查看非 Free 账号的周额度、周额度刷新时间、有效重置卡数量和到期时间，并提供手动或可选自动使用重置卡。

## 安装

在“插件管理 → 安装插件 → GitHub”填写 `Lemon-57/rs-quota-manager`，标签 `v0.1.4`，选择 `.tar.gz` 资产；也可下载资产及 `checksums.txt`，核对 SHA-256 后上传安装。
插件 ID 为 `personal.quota-manager`，自动使用默认关闭。

## 兼容与状态

- 宿主：`>=3.26.2, <3.27.0`；实际安装验证 v3.26.2。
- 平台：Linux x86_64，glibc 2.28+；本次未提供 ARM64 或 Windows 安装包。
- 基于公开 SDK 与官方 UI v0.4.1，指标与会员标识使用共享 ZCard、ZTag 组件。
- 3 项规则测试、27 项协议测试和 11 项前端测试通过，截图使用本地模拟数据。

## 功能与风险

显示完整邮箱、会员标识、周额度和重置卡库存；支持搜索、筛选、分页及内联检测设置。
自动使用前复核通用周限，优先最早到期有效卡；手动选卡需要确认。
持久化原请求标识，结果不确定时暂停该号消费，重试只确认原操作。
CSV 通过只读弹窗、复制和全选导出，不放宽隔离权限。

未进行真实卡片消费，消费路径使用模拟上游验证。自动或手动使用会真实消耗重置卡，操作不可撤回。
关闭开关不能撤回已经发出的消费请求，不同套餐和上游卡片格式仍可能存在兼容性差异。

本次安装包从该标签的独立源码快照在本机重新构建，文件摘要见附件 `checksums.txt`。
此前 v0.1.3 Release 因标签源码与旧安装包版本不一致已恢复为草稿；请使用本版本。
